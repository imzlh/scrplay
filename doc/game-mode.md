# 游戏模式（Game Mode）手册

scrplay 在 scrcpy 的投屏与控制内核之上增加了一个"游戏模式"：把电脑的键盘和
鼠标映射为**拟人化的合成触摸**，用来在桌面电脑上玩手机游戏和云游戏
（云游戏版《崩坏：星穹铁道》已实测可玩）。

本文是游戏模式的完整手册。scrcpy 原有功能（投屏、录制、HID 键鼠等）不受
影响，相关文档见 [README](../README.md#user-documentation) 的文档索引。

## 功能总览

- **虚拟摇杆 / 按键映射 / 滑动手势 / 鼠标瞄准**：WASD 驱动虚拟摇杆，鼠标
  移动拖动视角，鼠标与键盘按键映射为屏幕上的合成触摸点。
- **ImGui 编辑器**：在窗口内直接拖放控件、改键位、调参数，改完立即生效。
- **profile 与预设**：每个游戏一套 profile 文件，内部最多 12 个预设（例如
  "开放世界"、"回合制"），运行时一键切换。
- **运行模式 HUD**：显示当前预设、编辑/预设快捷键提示，鼠标松开时可弹出
  预设菜单。
- **反检测的拟人化输入**：摇杆拇指以 ease-out 轨迹滑动到位；触摸位置与
  时序带随机抖动；单击时长随机化；瞄准手指仅在鼠标捕获期间存在，松开
  鼠标（Alt）立即抬起。
- **客户端裁剪**：可按 profile 裁掉画面黑边，裁剪不影响已有控件坐标
  （坐标始终相对完整原始画面归一化）。

## 快速上手

需要先准备 `adb`，并在手机上打开 USB 调试；首次连接时在手机上确认
"允许 USB 调试"授权弹窗。

在仓库根目录构建（Linux）：

```bash
meson setup build -Dcompile_server=false
ninja -C build
```

仓库内已跟踪预编译的设备端服务端 `server/scrplay-server`，因此构建客户端
不需要 Android SDK / JDK。

然后启动游戏模式：

```bash
./run-game.sh
```

`run-game.sh` 是开发构建的启动脚本，它做三件事：

1. 设置 `SCRPLAY_SERVER_PATH` / `SCRPLAY_ICON_PATH` 指向仓库内的服务端和图标；
2. 若环境未配置输入法变量，自动探测 fcitx5 / ibus 并导出
   `SDL_IM_MODULE` 与 `XMODIFIERS`（原因见[下文](#中文输入)）；
3. `exec build/app/scrplay --game-mode "$@"`，即启动游戏模式并把额外参数
   透传给 scrplay。例如：

```bash
./run-game.sh --game-profile=default --max-size=1600
```

启动后默认进入**运行（play）模式**，鼠标被捕获用于控制视角。按 `Shift+E`
（可改）进入编辑器摆放控件，详见[编辑器](#编辑器)一节。

## 命令行选项

游戏模式新增以下选项（`./build/app/scrplay --help` 可查看完整帮助）：

| 选项 | 说明 |
| --- | --- |
| `--game-mode` | 启用游戏模式：键盘/鼠标映射 + 窗口内 profile/预设编辑器 |
| `--game-profile=<name>` | 启动时加载名为 `<name>` 的 profile。不指定时：若只有一个 profile 自动加载它；若存在多个，弹出窗口内的选择器 |
| `--game-font=<path>` | 指定游戏模式 UI 使用的 TTF 字体。默认自动探测（必须支持中文，见[中文输入](#中文输入)一节的字体列表） |
| `--game-ui-scale=<factor>` | UI 缩放系数，范围 0.5～4.0。默认自动探测桌面缩放（例如 125% HiDPI 显示器取 1.25） |

其余选项（`-s`/`--serial`、`--tcpip`、`-m`/`--max-size`、`--video-codec`、
`--record` 等）与上游 scrcpy 完全一致，见各专题文档。

## 两种运行时

游戏模式内部有两种运行时（runtime），随时切换：

- **映射运行时**（默认）：键盘鼠标交给当前预设的映射引擎，被映射的键
  转成合成触摸注入，未被映射的普通按键仍转发给设备（转发时剥离 Alt，
  因为 Alt 被用作本地解锁键）。
- **普通模式（native）**：完全回到普通 scrcpy 的输入处理，MOD 快捷键、
  HID 键鼠行为与不带 `--game-mode` 时一致。映射运行时中 MOD 快捷键不生效，
  需要这些快捷键时切到普通模式即可。

切换方式：HUD 预设快捷键**长按**进入普通模式，普通模式下**短按**返回上次
的映射预设（见[快捷键](#快捷键)）；或鼠标松开时通过 HUD 下拉菜单选择
"普通模式"。

## 运行模式操作

- **鼠标捕获**：映射运行时下鼠标被捕获（相对模式），鼠标移动即拖动视角
  （需要预设启用"鼠标瞄准"并有瞄准起点控件）。
- **Alt 临时解锁**：按住任一 Alt 键释放鼠标；松开全部 Alt 后自动重新捕获。
  HUD 上会显示"Alt 临时解锁"提示。
- **Alt + 左键拖动 = 直接触摸**：Alt 按住期间（鼠标未被捕获）按下左键
  拖动，会作为一根真实手指直接注入到对应位置——用于点按那些没有建映射
  的 UI 按钮。即使先松开 Alt 再松左键，触摸也能正确抬起。
- **悬停自动回收**：鼠标自由状态在游戏画面内停留约 2.5 秒后自动重新捕获；
  悬停在 HUD 上或窗口外则不会回收。
- **失焦保护**：窗口失去焦点时，所有按住的键与合成触摸立即释放，避免
  卡键。

## HUD

运行（映射）模式下窗口顶部居中显示 HUD，随使用场景自动变化：

- **鼠标捕获时**：显示一个非交互徽章，第一行是"配置名 · 当前预设"
  （普通模式下为"配置名 · 普通模式"），第二行依次是 `Alt 临时解锁`、
  编辑热键（默认 `Shift+E`）+ "编辑"、预设热键（默认 `F8`）+
  "短按预设 · 长按普通"（普通模式下为"短按返回游戏"）；热键名按 profile
  的 `hotkey` 配置实际显示。
- **游戏有操作时自动收起**；闲置 3 秒后重新滑出。完全收起后仍保留一个小
  徽章"控制 · <预设名>"提示当前控制模式。
- **鼠标自由时**（按住 Alt 或点击解锁）变为可交互条：配置名 + 预设下拉
  （含"普通模式"项）+ "编辑"按钮 + "锁定鼠标"按钮。收起状态下把鼠标移到
  窗口顶端即可唤出。
- 收起/展开使用 cubic ease-out 滑动动画（展开约 0.30 秒，收起约 0.22 秒）。

## 快捷键

以下"编辑""预设"两个组合键由 profile 的 `hotkey` 行配置，默认值如下；
所有快捷键仅在游戏窗口聚焦时生效。

| 按键 | 作用 |
| --- | --- |
| `Shift+E`（默认，可改） | 运行模式 ↔ 编辑模式 切换 |
| `F8`（默认，可改） | 短按：切换到下一个预设；长按（≥0.6 秒）：进入普通模式。普通模式下短按：返回上次的映射预设 |
| `Esc`（编辑模式） | 取消正在等待的按键绑定；退出裁剪编辑 |
| `Delete`（编辑模式） | 删除当前选中的控件 |

说明：

- 预设键**短按只在映射预设之间轮换**，不会误入普通模式；进入普通模式靠
  长按或 HUD 下拉菜单中的"普通模式"项。
- 运行时选择的预设与普通/映射状态只影响当前会话，**不会写入 profile
  文件**；下次启动仍从第一个预设开始。
- 普通 scrcpy 的 MOD 快捷键（`MOD+f` 全屏等）在映射运行时不可用，切到
  普通模式后恢复，`MOD` 默认为左 Alt / 左 Super（`--shortcut-mod` 可改）。

## 编辑器

`Shift+E`（或 HUD 上的"编辑"按钮）进入编辑模式；工具栏最左侧"返回"按钮
（或再按 `Shift+E`）回到运行模式。**退出编辑或切换配置时会同步保存**；
编辑过程中的改动通过 700ms 防抖自动保存，工具栏右侧显示保存状态
（"已自动保存 / 正在保存… / 保存失败"）。

### 工具栏

从左到右：

- **返回**：回到运行模式（悬停提示"返回运行模式"）。
- **添加虚拟摇杆 / 添加滑动移动 / 添加瞄准起点 / 添加按键映射**：在画面
  中央创建对应控件并选中（添加瞄准起点会自动打开该预设的"鼠标瞄准"）。
- **裁剪画面**：进入裁剪编辑，提供"完整画面 / 16:9 居中 / 完成裁剪"
  三个按钮；`Esc` 也可退出裁剪编辑。
- **打开/关闭详细面板**：切换右侧详细面板。
- 末尾是保存状态文字。

### 详细面板

面板标题为"游戏模式编辑"，自上而下：

1. **配置**：profile 下拉选择（最多列出 32 个）+ 铅笔（重命名配置）+
   加号（新建配置）。
2. **预设**：预设下拉 + 铅笔（重命名预设）+ 加号（从玩法模板新建预设）+
   垃圾桶（删除当前预设，至少保留 1 个）。
3. **控件列表**：当前预设的所有控件，点击选中。
4. **属性**：选中控件的参数：
   - **虚拟摇杆**：上/下/左/右四个方向键绑定、摇杆半径、高级位置（中心
     坐标 0～1）。
   - **按键映射**：单击(tap)/按住(hold)、触控范围、组合键修饰
     （Shift/Ctrl/Alt）、触发按键、高级位置。
   - **滑动移动**：触发按键、拖动时长（ms）、重复间隔（ms）、高级位置
     （起点/终点 0～1）；画面上绿色"起"点、蓝色"终"点可独立拖动，
     拖动连线整体移动。
   - **瞄准起点**：把准星拖到画面空旷处；高级位置可精确输入。
   - 通用：控件**名称**（显示用标签）与"删除此控件"按钮。
5. **鼠标瞄准**：启用相对鼠标拖动视角 + 灵敏度（0.10～5.00）。
6. **拟人抖动**：启用位置/时序随机扰动 + 抖动幅度（0.0000～0.0200）。

### 按键绑定

点击属性面板中的"触发按键"或摇杆方向按钮后进入等待状态（按钮显示
"…：按任意键…"），此时按下任意键盘键或鼠标键即完成绑定；`Esc` 取消。
组合键可先勾选 Shift/Ctrl/Alt 修饰再绑定基础键，例如 `ctrl+1`。

### 重命名与新建

- **重命名**弹窗（铅笔按钮）同时用于配置和预设；配置名会作为文件名，
  不允许空白、斜杠、反斜杠或控制字符；重命名配置成功保存后旧文件会被
  删除。
- **新建配置**弹窗创建一套独立的默认配置（含"默认"与"回合制(滑动移动)"
  两个预设）并自动切换；不会覆盖同名文件。

### 玩法模板

"从玩法模板新建"弹窗内置 8 种模板，填入常用键位和大致位置，创建后按
游戏画面对齐即可：

| 模板 | 说明 | 默认键位 |
| --- | --- | --- |
| 空白 | 从空画布开始 | 无默认键位 |
| 开放世界 | WASD 移动、鼠标视角与常用动作键 | WASD / 鼠标视角 / LMB / RMB / E / Q |
| 驾驶 | 方向、油门、刹车、手刹与加速 | WASD / Space / Shift / E / Q |
| 回合制 | 滑动移动与数字技能栏，不启用持续鼠标视角 | W 滑动 / LMB / 1-4 / Space |
| 射击 | 持续开火、瞄具与低灵敏度鼠标视角（0.85） | WASD / 鼠标视角 / LMB / RMB / E |
| MOBA即时战术 | 移动摇杆、四技能、装备与战术地图 | WASD / LMB / 1-4 / Q / F / Space |
| 横版动作 | 移动、攻击、跳跃、闪避与常用技能 | WASD / LMB / RMB / Space / Shift / E |
| 节奏音游 | 四轨按键时长同步，关闭随机位置扰动 | D / F / J / K 四轨 |

## Profile 文件格式

profile 保存在 `~/.config/scrplay/gameprofiles/<名称>.profile`，为带
schema 版本号的纯文本行格式，`#` 开头为注释，token 以空格/Tab 分隔。
编辑器保存时自动生成，也完全可以手写。

### 完整示例

```text
format 2
# 注释：坐标均为 0~1 归一化（相对完整原始画面）
profile default
hotkey edit=shift+e preset=f8
crop off

preset 默认
aim on sens=1.00
humanize on amp=0.0030
joystick center=0.171,0.777 radius=0.100 up=w down=s left=a right=d label=摇杆
bind key=lmb action=tap pos=0.850,0.752 size=0.080 label=普攻
bind key=rmb action=hold pos=0.850,0.752 size=0.080 label=重击
bind key=e action=tap pos=0.760,0.852 size=0.065 label=技能
bind key=q action=tap pos=0.800,0.700 size=0.055 label=爆发
bind key=shift action=hold pos=0.931,0.852 size=0.060 label=冲刺
bind key=space action=tap pos=0.600,0.905 size=0.050 label=跳跃
bind key=f action=tap pos=0.500,0.760 size=0.050 label=交互
bind key=tab action=tap pos=0.950,0.070 size=0.045 label=地图
aim start=0.550,0.250 label=瞄准起点

preset 回合制(滑动移动)
aim off
humanize on amp=0.0040
swipe key=w from=0.50,0.62 to=0.50,0.42 dur=280 every=520 label=移动
bind key=lmb action=tap pos=0.88,0.72 size=0.10 label=普攻
bind key=ctrl+1 action=tap pos=0.62,0.80 size=0.07 label=技能1
```

### 逐项说明

profile 级（每个文件最多一份）：

| 行 | 说明 |
| --- | --- |
| `format 2` | **必须**是第一个有效行，且当前只接受 `2` |
| `profile <名称>` | profile 名，也是文件名（去掉 `.profile` 后缀）；不允许空白、`/`、`\`、控制字符，不能是 `.` 或 `..`；必须与文件名一致，否则加载报 "profile name does not match its file name" |
| `crop off` 或 `crop rect=l,t,r,b` | 客户端裁剪矩形，坐标 0～1 归一化，最小宽高 0.01 |
| `hotkey edit=<组合键> preset=<组合键>` | 编辑与预设快捷键，仅限键盘键，可带 `shift+`/`ctrl+`/`alt+` 前缀（如 `shift+e`、`f8`） |

preset 级（`preset <名称>` 开启一个预设，名称为单个不含空白的 token，
最多 12 个预设）：

| 行 | 说明 |
| --- | --- |
| `aim on\|off [sens=<0.10~5.00>]` | 是否启用鼠标瞄准与灵敏度 |
| `humanize on\|off [amp=<0.00~0.02>]` | 是否启用拟人抖动与幅度（相对画面高度的最大随机位置偏移） |
| 控件行 | 见下表，每个预设最多 48 个控件 |

控件级：

| 行 | 说明 |
| --- | --- |
| `joystick center=<x>,<y> radius=<r> up=<键> down=<键> left=<键> right=<键> [label=<名称>]` | 虚拟摇杆；`radius` 相对画面高度，0.001～0.499；四方向键必须绑定（`none` 视为未绑定，校验报错） |
| `bind key=<键> action=tap\|hold pos=<x>,<y> size=<s> [label=<名称>]` | 按键映射；`action=tap` 按下后约 3 个引擎节拍（~50ms）自动抬起并带随机 ±1 拍；`action=hold` 按住期间保持触摸；`size` 相对画面高度，0.001～0.499 |
| `swipe key=<键> from=<x>,<y> to=<x>,<y> dur=<40~5000> every=<60~30000> [label=<名称>]` | 滑动手势；按住触发键时每 `every` 毫秒重复一次 `dur` 毫秒的滑动；`every < dur` 时校验给出警告 |
| `aim start=<x>,<y> [label=<名称>]` | 瞄准起点；一个预设最多一个（多个报错）。瞄准手指从这里按下并持续滑动，触及画面边缘 8% 安全边距时立即抬起并从起点重新开始 |

所有坐标 `x,y` 均为 0.00～1.00 的浮点数，**相对完整原始画面**（即使启用
裁剪也不变）。`label` 可包含普通空格；行内解析不接受首尾空格、连续空格或
其他空白字符（出现即解析失败），编辑器输入时会自动把空白规整为单个空格；
省略时使用默认标签（方向键名或"瞄准起点"）。

### `aim` 行歧义（重要）

`aim` 既是**预设级开关**也是**控件行**，两个行首 token 相同：

- `aim on` / `aim off`（可跟 `sens=`）→ 预设级瞄准开关；
- `aim start=<x>,<y>` → 瞄准起点控件。

解析器靠**第二个 token 消歧**：以 `start=` 开头按控件解析，`on`/`off`
按预设开关解析。手写 profile 时注意：写 `aim on` 后还必须有一行
`aim start=...` 才有实际瞄准行为（只开开关没有起点只会在校验中给出
警告，不会报错）；反之有 `aim start=` 而未写 `aim on` 时瞄准不生效。

### 键名

可用于 `up/down/left/right`、`key=`、`hotkey` 的键名：

- 单字符：`a`～`z`、`0`～`9`
- 功能键：`f1`～`f12`
- 命名键：`space` `tab` `enter` `esc` `shift` `ctrl` `alt` `up` `down`
  `left` `right`
- 鼠标键：`lmb` `rmb` `mmb` `m4` `m5`
- `none`（仅用于表示未绑定；绑定校验要求摇杆方向与触发键实际绑定）
- 组合键：`shift+`/`ctrl+`/`alt+` 前缀 + 单个基础键，如 `ctrl+shift+1`
  （`hotkey` 行的修饰写在同名前缀里，如 `edit=shift+e`）

### 数值范围与上限速查

| 项 | 范围 |
| --- | --- |
| 坐标/位置 | 0.00 ～ 1.00 |
| 摇杆半径、触控范围 size | 0.001 ～ 0.499（相对画面高度） |
| 瞄准灵敏度 sens | 0.10 ～ 5.00 |
| 拟人抖动幅度 amp | 0.00 ～ 0.02 |
| 滑动时长 dur | 40 ～ 5000 ms |
| 滑动重复间隔 every | 60 ～ 30000 ms |
| 裁剪最小宽高 | 0.01 |
| 预设数量 | ≤ 12 |
| 每预设控件数 | ≤ 48 |
| profile / 预设名长度 | ≤ 64 字节 |
| 控件标签长度 | ≤ 32 字节（UTF-8） |
| profile 文件大小 | ≤ 1 MiB |

## 配置文件布局

Linux（遵循 XDG）：

```text
~/.config/scrplay/
├── gameprofiles/
│   └── default.profile        # 每个 profile 一个 .profile 文件
└── gameui.ini                 # 编辑器/HUD 的 ImGui 窗口布局
```

- 设置了 `XDG_CONFIG_HOME` 时使用 `$XDG_CONFIG_HOME/scrplay/`。
- Windows 使用 `%APPDATA%\scrplay\scrplay\`（SDL 预定义路径）。
- 旧版本使用 `~/.config/scrcpy/`；**首次运行 scrplay 时会自动把旧目录
  迁移（复制）到 `~/.config/scrplay/`**，无需手工操作；旧目录保留不动，
  迁移失败也不影响启动（新位置从默认配置开始）。
- 首次运行且没有任何 profile 时，自动创建名为 `default` 的默认配置
  （面向 ARPG 的"默认"预设 + "回合制(滑动移动)"预设）；存在多个 profile
  且未指定 `--game-profile` 时弹出"选择游戏配置"选择器，其中也可新建
  （会基于默认内容）与删除。

## 中文输入

编辑器的配置/预设/控件名称输入框需要桌面输入法支持。SDL2 在
X11/XWayland 下**必须**显式设置 `SDL_IM_MODULE` 与 `XMODIFIERS` 才会连接
输入法，否则 fcitx5 等根本接不上窗口、无法输入中文。`run-game.sh` 会在
这两个变量都为空时自动探测并设置（fcitx5 优先，其次 ibus）；如果你的
环境已有输入法配置则不会覆盖。

游戏模式 UI 的默认字体按以下顺序自动探测（均支持中文），也可用
`--game-font` 指定：

- `/usr/share/fonts/opentype/noto/NotoSansCJK-Medium.ttc`（优先 Medium 字重，
  移动画面上更清晰）
- `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`
- `/usr/share/fonts/opentype/noto/NotoSansCJKsc-Regular.otf`
- `/usr/share/fonts/noto-cjk/NotoSansCJK-Regular.ttc`
- `/usr/share/fonts/truetype/wqy/wqy-microhei.ttc`
- `/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc`
- macOS：PingFang、STHeiti
- Windows：`msyh.ttc`

映射运行时会主动关闭文本输入（SDL 文本输入在桌面端默认开启），避免单独
按 Shift 被输入法劫持；只有在编辑器/选择器需要打字时才重新开启。

## 自测模式

设置环境变量 `SCRPLAY_GAME_SELFTEST` 后，映射引擎不再响应真实键盘，改为
按固定时间线注入脚本化输入，用于无人工参与地验证触摸注入链路：

| 时刻 | 动作 |
| --- | --- |
| 1.0s | 按下 `W` |
| 2.0s | 抬起 `W` |
| 2.6s | 按下 `E`（2.68s 抬起，触发 tap） |
| 3.4s | 按下 `Ctrl+1`（3.48s 抬起） |

- 每一步都会向 stderr 打印 `SELFTEST: ...` 行。
- `SCRPLAY_GAME_SELFTEST_DELAY=<秒>`（1～3599）可整体推迟时间线起点。
- 仓库根目录的 `selftest.sh` 封装了完整流程：等待设备 → 打开
  "显示触摸" → 以自测模式启动 → 连拍截屏 → 拉取 logcat，便于事后核对
  触摸圆点落点。

## 已知限制与实测说明

- **实测设备**：OPPO R11s。游戏模式在该设备 + 云游戏版《崩坏：星穹铁道》
  上开发验证；其他设备/游戏未逐一验证，控件位置需要按自己的画面调整。
- **断线即退出**：adb 连接断开时 scrplay 运行会结束（退出码 2，含义
  "Device disconnected while running"）。程序不会自动重连，重新插好
  USB（或恢复网络）后再次运行 `./run-game.sh` 即可。运行过程中画面
  分辨率或横竖屏变化（帧尺寸变化）会释放全部合成触摸，属于预期行为。
- **云游戏画面比例**：profile 坐标相对完整原始画面归一化，云游戏分辨率
  变化不影响已有绑定；用客户端裁剪去黑边时同样不影响。
- **编辑器打字需要输入法**：见[中文输入](#中文输入)一节；在纯 Wayland
  （非 XWayland）会话下未验证。
